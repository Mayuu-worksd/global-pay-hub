# Global Pay Hub

Build a production-ready fintech platform inspired by UniPayment, Stripe and Wise.

Tech stack:

- Next.js 15

- TypeScript

- Tailwind CSS

- shadcn/ui

- Supabase

Design requirements:

- Minimalist + premium fintech design

- White background with blue accents (#1677FF)

- Enterprise-level UI

- Smooth animations and glassmorphism

- Responsive for desktop and mobile

Pages:

- Landing page

- Login page

- Signup page

- Google authentication

- Forgot password

Navbar:

- Products

- Solutions

- Developers

- Pricing

- Contact

- Login

- Get Started

Hero section:

"Global Hybrid Payment Infrastructure"

Features:

- Fiat wallets

- Crypto wallets

- Virtual bank accounts

- Currency exchange

- International payouts

Create the complete routing structure and authentication flow using Supabase Auth and Google login.
